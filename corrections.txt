HOW CORRECTIONS WORK
====================

Game rows in the tabs "Spiele" and "legacy" are never edited by hand.
Every fix is a row in the tab "corrections". The app reads that tab on
every load and applies the rows. Delete a row to undo it.


1. THE TAB
----------

Columns (the order doesn't matter, the app finds them by header):

  game_ref | action | note | played_at | wrong_player | right_player

  game_ref   Which game. The game's Zeitstempel, best copied from the
             app's game page (at the bottom). Copying it from the sheet
             also works: "dd.mm.yyyy hh:mm:ss" from Spiele or
             "yyyy-mm-dd hh:mm:ss" from legacy, as text or as a date cell.
  action     void, swap, move or replace (see below).
  note       Free text for yourself, e.g. who reported it. Optional.
  played_at  Only for move: when the game was really played.
  wrong_player, right_player
             Only for replace: the name entered by mistake and the
             player who really played.
Leave the columns an action doesn't use empty.

The headers "played_at", "wrong_player" and "right_player" have to be
added once by hand, at the end.


2. THE FOUR ACTIONS
-------------------

  void   The game is removed. Use it for test entries, duplicates and
         games that never happened.

  swap   Winners and losers are exchanged. Use it when the right people
         were entered but the wrong side won.

  move   The game counts at the time it was really played, given in
         played_at. Use it for games entered late.
         played_at: a date-time cell, or text "dd.mm.yyyy hh:mm" or
         "yyyy-mm-dd hh:mm" (seconds optional). A rough time is fine,
         but it needs a time of day and must not be later than the entry.

  replace
         One player is exchanged for another, wherever they stand
         (winner or loser, singles or doubles). Use it when a wrong
         name was picked in the form. Any name of a player works (old
         names too), upper or lower case doesn't matter. A misspelt
         name that isn't a player at all can be fixed the same way.

A moved game keeps its Zeitstempel (the entry time). So links to it and
other correction rows still find it under that Zeitstempel. Everything
else (order, Elo, Plätze, streaks, badges, week and month) uses
played_at. The game page shows "Nachgetragen" with both times.


3. COMMON CASES
---------------

Forgotten game
  1. Enter it in the Ergebnis form as usual.
  2. Open it in the app (Letzte Spiele) and copy its Zeitstempel.
  3. Add a row:  <Zeitstempel> | move | forgotten | <when it was played>

Wrong winner (right players, wrong side won)
  One row:  <Zeitstempel> | swap | <note>

Wrong player (e.g. the wrong opponent)
  One row:  <Zeitstempel> | replace | <note> | | Bernd | Clara
  (Bernd was entered, Clara really played.) Two wrong players in one
  game: two rows. The result is exactly as if the game had been entered
  correctly.

Game entered twice
  Void one of the two:  <Zeitstempel> | void | duplicate

Interpolated time of an old (legacy) game is off
  <Zeitstempel> | move | <note> | <real time>


4. RULES
--------

- One game may have several rows, e.g. swap, move and replace.
  replace rows apply in their order in the tab.
- void wins over everything else.
- Two move rows for the same game: the later row counts, and the app
  shows a hint.
- A played_at before responses_valid_from is allowed (a paper game
  entered late). The legacy migration never has to be re-run for that.
- Entries in Spiele before responses_valid_from are test data and stay
  ignored, even with a correction row. The cutoff uses the entry time.
- Moved games don't count for the time-of-day badges or the Labor's
  session and hour analyses, because a typed-in time is only rough.


5. CHECKING
-----------

After adding rows, open the app and refresh. The menu item "Daten und
Hinweise" counts the corrections ("gestrichen", "mit vertauschtem
Ergebnis", "nachgetragen", "mit korrigiertem Spieler") and lists every row it could not apply, with the row number. Typical
reasons: the Zeitstempel matches no game, the action is misspelled, or
played_at is empty, unreadable, has no time of day or lies after the
entry, wrong_player doesn't play in that game, right_player is not a
player or already plays in it. A row with a problem changes nothing.

Alle Spiele -> filter "korrigiert" lists every corrected game. The game
page says what was corrected ("Nachgetragen", "Spieler korrigiert:
Clara statt Bernd").
